De Casteljau's algorithm

正态分布是唯一满足对称性、有限方差、最大熵的分布

------------------------------------------------------------------------------
a cross b = det | i  j  k  |
                | a1 a2 a3 |
                | b1 b2 b3 |
     = (a2*b3 - a3*b2)*i - (a1*b3 - a3*b1)*j + (a1*b2 - a2*b1)*k

-*- 四元数 -*-

# 定义和运算规则
Q = s + x*i + y*j + z*k
i^2 = -1
j^2 = -1
k^2 = -1
i*j*k = -1
i*j = k
j*k = i
k*i = j
j*i = -k
k*j = -i
i*k = -j
# 四元数的模
|Q| = sqrt(s^2 + x^2 + y^2 + z^2)
------------------------------------------------------------------------------
*. 四元数乘法
------------------------------------------------------------------------------
三维向量a = (a1, a2, a3) 对应为纯虚四元数
A = a1*i + a2*j + a3*k
三维向量b = (b1, b2, b3) 对应为
B = b1*i + b2*j + b3*k

A*B = (a1*i + a2*j + a3*k)(b1*i + b2*j + b3*k)
    = -(a1*b1 + a2*b2 + a3*b3)
     + (a2*b3 - a3*b2)*i
     - (a1*b3 - a3*b1)*j
     + (a1*b2 - a2*b1)*k
    = -(a dot b) + a cross b

A*B = (a0 + a1*i + a2*j + a3*k)(b0 + b1*i + b2*j + b3*k)
    =   a0*b0   + a0*b1*i   + a0*b2*j   + a0*b3*k
      + a1*b0*i + a1*b1*i^2 + a1*b2*i*j + a1*b3*i*k
      + a2*b0*j + a2*b1*j*i + a2*b2*j^2 + a2*b3*j*k
      + a3*b0*k + a3*b1*k*i + a3*b2*k*j + a3*b3*k^2
    =    a0*b0 - a1*b1 - a2*b2 - a3*b3
      + (a0*b1 + a1*b0 + a1*b3 - a3*b2) * i
      + (a0*b2 + a2*b0 + a3*b1 - a1*b3) * j
      + (a0*b3 + a3*b0 + a1*b2 - a2*b1) * k
    = a0*b0 - (a dot b) + a0*b + b0*a - (a cross b)

------------------------------------------------------------------------------
*. 任意单位纯虚四元数N，都具有与复数单位i类似的性质：N^2 = -1
------------------------------------------------------------------------------
    N = n1*i + n2*j + n3*k
    N^2 = n1^2*i^2 + n2^2*j^2 + n3^2*k^2
          + n1*n2*i*j + n1*n3*i*k
          + n2*n1*j*i + n2*n3*j*k
          + n3*n1*k*i + n3*n2*k*j
        = n1^2*i^2 + n2^2*j^2 + n3^2*k^2
          + n1*n2(i*j + j*i)
          + n2*n3(j*k + k*j)
          + n1*n3(i*k + k*i)
        = -(n1^2 + n2^2 + n3^2)
        = -1

------------------------------------------------------------------------------
*. 共轭四元数
------------------------------------------------------------------------------
Q  = s + x*i + y*j + z*k 的共轭四元数定义为
Q` = s - x*i - y*j - z*k

Q*Q` = s^2 - s*x*i - s*y*j - s*z*k
       + s*x*i - x^2*i^2 - x*y*i*j - x*z*i*k
       + s*y*j - x*y*j*i - y^2*j^2 - y*z*j*k
       + s*z*k - x*z*k*i - z*y*k*j - z^2*k^2
     = s^2 + x^2 + y^2 + z^2
     = |Q|^2 = |Q`|^2

# 共轭两次恢复原值
# 对加法逐项取共轭 (A + B)` = A` + B`
# 共轭不改变模长
# 对乘积取共轭时，顺序反转 (A*B)` = B`*A`
A*B    =    a0*b0 - a1*b1 - a2*b2 - a3*b3
         + (a0*b1 + a1*b0 + a1*b3 - a3*b2) * i
         + (a0*b2 + a2*b0 + a3*b1 - a1*b3) * j
         + (a0*b3 + a3*b0 + a1*b2 - a2*b1) * k
(A*B)` =    a0*b0 - a1*b1 - a2*b2 - a3*b3
         - (a0*b1 + a1*b0 + a1*b3 - a3*b2) * i
         - (a0*b2 + a2*b0 + a3*b1 - a1*b3) * j
         - (a0*b3 + a3*b0 + a1*b2 - a2*b1) * k
B`*A`  =    b0*a0 - (-b1)*(-a1) - (-b2)*(-a2) - (-b3)*(-a3)
         + (b0*(-a1) + (-b1)*a0 + (-b1)*(-a3) - (-b3)*(-a2)) * i
         + (b0*(-a2) + (-b2)*a0 + (-b3)*(-a1) - (-b1)*(-a3)) * j
         + (b0*(-a3) + (-b3)*a0 + (-b1)*(-a2) - (-b2)*(-a1)) * k
       =    a0*b0 - a1*b1 - a2*b2 - a3*b3
         - (a0*b1 + a1*b0 + a1*b3 - a3*b2) * i
         - (a0*b2 + a2*b0 + a3*b1 - a1*b3) * j
         - (a0*b3 + a3*b0 + a1*b2 - a2*b1) * k

# 乘积的模等于模的乘积 |A*B| = |A|*|B|
|A*B|^2 = (A*B)(A*B)`
        = (A*B)(B`*A`)
        = A*(B*B`)*A`
        = A*|B|^2*A`
        = |B|^2*A*A`
        = |B|^2*|A|^2
        = |A|^2*|B|^2
        = (|A|*|B|)^2

*. 四元数的逆元公式
------------------------------------------------------------------------------
Q^-1 = Q`/|Q|^2
只有当Q是单位四元数，即|Q|=1时，共轭才直接等于逆元

------------------------------------------------------------------------------
*. 四元数旋转公式
------------------------------------------------------------------------------
向量v = (v1, v2, v3) 绕单位轴 n = (n1, n2, n3) 按右手规则旋转theta角的结果
向量w = (w1, w2, w3)
  # 让右手拇指指向单位向量n的方向, 其余四指自然弯曲
    四指弯曲的方向就是正角度的旋转方向

考虑变换W = Q*V*Q`, 其中Q是一个单位四元数
W` = (Q*V*Q`)` = Q``*V`*Q` = Q*V`*Q` = -Q*V*Q` = -W
说明W是纯虚四元数
同时|W| = |Q|*|V|*|Q`| = |V|
说明该变换保持结果仍然是纯虚四元数，并且模长不变
旋转轴N使用该变化后本身必须保持不动, 因而要求
Q*N*Q` = N
  => Q*N*Q`*Q = N*Q
  => Q*N = N*Q

设 Q = a + U 其中U是向量u对应的纯虚四元数
   Q*N - N*Q = 2(u cross n) = 0
u cross n = 0 要求u和n平行, 所以Q要求有形式 Q = a + b*N
|Q| = 1 要求 a^2 + b^2 = 1 这意味着(a,b)在单位圆上，可以用某个角度alpha参数化
Q就有形式Q = cos(alpha) + sin(alpha)*N

令V = v1*i + v2*j + v3*k
令Q  = cos(theta/2) + (n1*i + n2*j + n3*k)*sin(theta/2)
  Q` = cos(theta/2) - (n1*i + n2*j + n3*k)*sin(theta/2)
  |Q| = cos(theta/2)^2
        + n1^2*sin(theta/2)^2
        + n2^2*sin(theta/2)^2
        + n3^2*sin(theta/2)^2
      = cos(theta/2)^2 + sin(theta/2)^2
      = 1
  |Q`| = 1
